# Hayagriva roadmap

## V1 Core
Voice + TTS + dark UI + modes + permissions + Gemini backend.

## V2 Vision
CameraX, ML Kit face tracking, image understanding, visual search.

## V3 Automation
Notifications, SMS/calls where permitted, calendar, alarms, media, accessibility.

## V4 Intelligence
Deep research, coding, math, translation, meetings, finance, memory.

## V5 Ecosystem
Desktop, USB portable companion, TV, Wear OS, family hub.

All production integrations should use explicit permissions, secure credentials, and user consent.
